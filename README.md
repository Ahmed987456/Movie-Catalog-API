# Movie Catalog API

ASP.NET Core Web API for managing movies and genres.

## Features

- Add / Update / Delete Movies
- Manage Genres
- Filter movies by genre
- RESTful API design

## Technologies

- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- C#

## Endpoints

### Movies
- GET /api/movies
- POST /api/movies
- PUT /api/movies
- DELETE /api/movies

### Genres
- GET /api/genres
- POST /api/genres

## Notes

This project demonstrates backend API development using .NET Core.
